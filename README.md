## Featured Projects

### 🤖 AI PDF Chatbot (RAG)
AI-powered PDF chatbot using Retrieval-Augmented Generation that extracts information from uploaded PDF documents and answers user questions through semantic retrieval and an LLM.

**Tech:** Python, LangChain, FAISS, HuggingFace Embeddings, Groq LLM, Streamlit, RAG

[🚀 Live Demo](https://ai-pdf-chatbot-rag-w2tmc2qdjbxlfwktvcmqre.streamlit.app/) · [💻 GitHub](https://github.com/Ombankar1111-gi/ai-pdf-chatbot-rag)

---

### 🎥 AI Video Assistant
AI-powered meeting/video intelligence application that transcribes audio, generates summaries, extracts action items and key decisions, and enables RAG-based chat over the transcript.

**Tech:** Whisper, LangChain, ChromaDB, Mistral AI, Python, Streamlit

[🚀 Live Demo](https://ai-video-assistant-wvlx.onrender.com) · [💻 GitHub](https://github.com/Ombankar1111-gi/ai-video-assistant)

---

### 📈 Customer Churn Prediction System
End-to-end ML system that predicts telecom customer churn probability and provides risk-based retention recommendations. Covers data cleaning, EDA, and comparison across Logistic Regression, Random Forest, and Gradient Boosting (Random Forest selected — **ROC-AUC 0.844, Accuracy 0.762**). Supports single and batch CSV scoring, deployed on Render.

**Tech:** Python, Pandas, NumPy, Scikit-learn, Random Forest, Streamlit

[🚀 Live Demo](https://customer-churn-prediction-imoq.onrender.com/) · [💻 GitHub](https://github.com/Ombankar1111-gi/customer-churn-prediction)

---

### 🏠 House Price Prediction System
Machine learning application that predicts median house value using the California housing dataset, comparing Linear Regression and Random Forest models with an interactive Streamlit dashboard, deployed on Render.

**Tech:** Python, Pandas, Scikit-learn, Streamlit, Machine Learning, Random Forest / Linear Regression

[🚀 Live Demo](https://house-price-prediction-5mex.onrender.com/) · [💻 GitHub](https://github.com/Ombankar1111-gi/house-price-prediction)

---

### 🧠 Mental Health Score Predictor
